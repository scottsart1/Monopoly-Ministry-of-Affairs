# Velvet & Roulette

A date-night game for two: a spinning activity wheel with timers, a night that
follows the shape of a night (warm-up → foreplay → sex → finish), a private
Limits Sheet, and D/s scene modes. Everything runs on the phone; nothing is
sent anywhere.

- **Play in a browser:** open `index.html` (the `fonts/` folder ships alongside it).
- **Install on Android:** download the latest `.apk` from the
  [Releases](../../releases) page. It asks for one permission (vibration) and
  has no network access at all.
- **How it all works:** [README-wheel.md](README-wheel.md).
- **Building / releasing the Android app:** [packaging/android-wrapper/README.md](packaging/android-wrapper/README.md).

Consent is only ever given directly: nothing on the Limits Sheet counts until it
is a Yes on both sides.
